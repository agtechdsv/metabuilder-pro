# v1.0.7 — release notes (rascunho para colar no painel)

```
=== pt ===
## 🚀 MetaBuilder PRO v1.0.7

### ⚙️ Automações (BPM)
- **Fluxos publicados voltam a disparar:** o agente de conexão agora recebe seus fluxos ativos direto da plataforma, de forma segura. Antes, em alguns projetos ele iniciava com 0 fluxos e nada era executado (nem e-mails de aviso).
- **Mensagem de falha clara:** se o agente não conseguir buscar os fluxos, o erro aparece no log do túnel e os fluxos já carregados continuam valendo.

### 🧭 Novidades na plataforma
- **Histórico de versões do aplicativo:** em aplicativos acessados online (ou no navegador da IDE), o histórico mostra a versão Web, em vez de uma lista vazia.

=== en ===
## 🚀 MetaBuilder PRO v1.0.7

### ⚙️ Automations (BPM)
- **Published flows fire again:** the connection agent now receives your active flows straight from the platform, securely. Before, in some projects it started with 0 flows and nothing ran (not even alert emails).
- **Clear failure message:** if the agent can't fetch the flows, the error shows in the tunnel log and the flows already loaded stay in effect.

### 🧭 Platform news
- **App version history:** for apps opened online (or in the IDE browser), the history shows the Web version instead of an empty list.

=== es ===
## 🚀 MetaBuilder PRO v1.0.7

### ⚙️ Automatizaciones (BPM)
- **Los flujos publicados vuelven a ejecutarse:** el agente de conexión ahora recibe sus flujos activos directamente de la plataforma, de forma segura. Antes, en algunos proyectos iniciaba con 0 flujos y no se ejecutaba nada (ni siquiera los correos de aviso).
```
