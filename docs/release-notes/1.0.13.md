=== pt ===
## 🚀 MetaBuilder PRO v1.0.13

### 📊 Relatórios agendados (BPM)
- **Nova janela "Escolher colunas":** monte o relatório navegando pelas tabelas. Entre nas tabelas relacionadas até **4 níveis** (Pedido › Cliente › Cidade › Estado), ache qualquer campo pela busca e veja o caminho completo de cada coluna. Os campos de controle (criado em, atualizado por...) ficam recolhidos e as colunas de senha e token não aparecem.
- **Título e ordem das colunas:** troque o título de cada coluna (por exemplo "Cliente" em vez de "Cliente › Nome") e arrume a ordem na própria janela. O que você escolheu aparece resumido na ação.
- **Nome no lugar do código:** a coluna de relacionamento (como o código do cliente) agora pode ser trocada pelo nome da tabela relacionada.
- **Variáveis do resultado da consulta:** o menu "+ Variável" do e-mail lista o nome real de cada consulta do fluxo (por exemplo `pedidos.total` e `pedidos.tabela`), em vez de um nome genérico que não funcionava.
- **E-mail sem usuário:** em envios agendados, que não têm usuário logado, `{{usuario.nome}}` e as variáveis do usuário saem vazias, em vez de aparecerem como código no texto.

### 🧭 Novidades na plataforma
- **Painel do SuperAdmin em três idiomas:** Dashboard, Clientes, Cobranças, Agenda, iClub, NFS-e, Regras de Preço, Campanhas, MetaVoice, Arquivos e Releases agora seguem o idioma escolhido. Valores e datas também acompanham o idioma.

=== en ===
## 🚀 MetaBuilder PRO v1.0.13

### 📊 Scheduled reports (BPM)
- **New "Choose columns" window:** build the report by browsing the tables. Step into related tables up to **4 levels** (Order › Customer › City › State), find any field with the search and see the full path of each column. Control fields (created at, updated by...) stay collapsed and password and token columns are hidden.
- **Column title and order:** change each column's title (for example "Customer" instead of "Customer › Name") and arrange the order in the same window. What you chose appears summarized in the action.
- **Name instead of code:** a relationship column (such as the customer code) can now be swapped for a field of the related table, like the name.
- **Query result variables:** the "+ Variable" menu in the email lists the real name of each query in the flow (for example `pedidos.total` and `pedidos.tabela`), instead of a generic name that did not work.
- **Email without a user:** in scheduled sends, which have no logged-in user, `{{usuario.nome}}` and the other user variables come out empty, instead of showing as code in the text.

### 🧭 Platform news
- **SuperAdmin panel in three languages:** Dashboard, Clients, Charges, Calendar, iClub, NFS-e, Pricing Rules, Campaigns, MetaVoice, Files and Releases now follow the chosen language. Amounts and dates follow the language too.
