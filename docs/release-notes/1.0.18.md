# v1.0.18 — release notes (rascunho para colar no painel)

=== pt ===
## 🚀 MetaBuilder PRO v1.0.18

### ✅ Aprovações nos fluxos
- **Tabelas criadas pelo administrador do banco:** quando o usuário do banco do Agente não tem permissão para criar tabelas, o administrador roda o script das aprovações uma vez e o fluxo passa a funcionar normalmente. Antes, o Agente ainda tentava criar as tabelas a cada pedido e falhava com "permissão negada", e a tarefa de aprovação não era registrada.
- Se as tabelas ainda não existirem e o usuário do banco não puder criá-las, o aviso continua indicando o script a rodar.

### 🗄️ Tabelas do MetaBuilder no banco do cliente
- **Script único para o administrador do banco:** um arquivo com todas as tabelas que o Agente usa (aprovações, votos da Ajuda contextual e log de banco) e as permissões do usuário do Agente.
- O mesmo ajuste vale para a **Ajuda contextual** e para o **log de banco**: com as tabelas já criadas pelo administrador, o Agente passa a usá-las em vez de tentar criá-las e falhar.

=== en ===
## 🚀 MetaBuilder PRO v1.0.18

### ✅ Approvals in flows
- **Tables created by the database administrator:** when the Agent's database user is not allowed to create tables, the administrator runs the approvals script once and the flow then works normally. Before, the Agent kept trying to create the tables on every request and failed with "permission denied", so the approval task was never recorded.
- If the tables do not exist yet and the database user cannot create them, the warning still points to the script to run.

### 🗄️ MetaBuilder tables in the customer's database
- **A single script for the database administrator:** one file with all the tables the Agent uses (approvals, contextual Help votes and database log) and the Agent user's permissions.
- The same fix applies to **contextual Help** and to the **database log**: with the tables already created by the administrator, the Agent uses them instead of trying to create them and failing.

=== es ===
## 🚀 MetaBuilder PRO v1.0.18

### ✅ Aprobaciones en los flujos
- **Tablas creadas por el administrador de la base:** cuando el usuario de base de datos del Agente no tiene permiso para crear tablas, el administrador ejecuta el script de las aprobaciones una sola vez y el flujo pasa a funcionar normalmente. ### 🗄️ Tablas de MetaBuilder en la base del cliente
- **Un script único para el administrador de la base:** un archivo con todas las tablas que usa el Agente (aprobaciones, votos de la Ayuda contextual y log de base de datos) y los permisos del usuario del Agente.
- El mismo ajuste vale para la **Ayuda contextual** y para el **log de base de datos**: con las tablas ya creadas por el administrador, el Agente las usa en lugar de intentar crearlas y fallar.
