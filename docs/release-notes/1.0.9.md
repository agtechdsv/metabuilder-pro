# v1.0.9 — release notes (rascunho para colar no painel)

=== pt ===
## 🚀 MetaBuilder PRO v1.0.9

### ⚙️ Automações (BPM)
- **E-mail para grupos de usuários funciona:** ao escolher um grupo (por exemplo, *Administrador*) como destinatário, todos os membros agora recebem o e-mail, ou só os usuários que você marcar dentro do grupo. Antes, o grupo ficava vazio sem aviso e só os e-mails digitados recebiam.
- **Data e hora nos fluxos:** em qualquer campo com *+ Variável* há o grupo **Sistema**, com a data atual, a hora atual e a data e hora atuais.
- **Usuário logado nos fluxos:** o grupo **Usuário logado** traz o nome, o e-mail e o ID de quem fez a ação no aplicativo. Exemplo: *Pedido excluído por {{usuario.nome}} em {{sistema.data_hora}}*. Em fluxos sem pessoa na tela (agendado e webhook), esses campos ficam em branco.
- **Variáveis na mensagem de bloqueio:** a mensagem do nó *Resposta* também aceita *+ Variável*, como o número do pedido.
- **Aba Mensagem mais limpa:** textos antigos que apareciam com marcas estranhas (como *&nbsp;*) agora aparecem normais.

=== en ===
## 🚀 MetaBuilder PRO v1.0.9

### ⚙️ Automations (BPM)
- **Email to user groups works:** when you pick a group (for example, *Administrator*) as the recipient, all its members now get the email, or only the users you tick inside the group. Before, the group came out empty with no warning and only the typed addresses received it.
- **Date and time in flows:** every field with *+ Variable* now has a **System** group, with the current date, current time and current date and time.
- **Logged-in user in flows:** the **Logged-in user** group brings the name, email and ID of whoever did the action in the app. Example: *Order deleted by {{usuario.nome}} on {{sistema.data_hora}}*. In flows with nobody on screen (scheduled and webhook), these fields stay blank.
- **Variables in the block message:** the message of the *Response* node also accepts *+ Variable*, such as the order number.
- **Cleaner Message tab:** old texts that showed odd marks (such as *&nbsp;*) now look normal.

=== es ===
